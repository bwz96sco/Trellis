# Research: Exact Retired-Host Generated Path Sets

- **Query**: Freeze the exact generated path sets that must remain cleanup-known after the active registry shrinks to Claude Code and Codex.
- **Scope**: internal
- **Date**: 2026-07-18

## Findings

These paths are the current `collectPlatformTemplates(id)` outputs for the 17 hosts to retire. Source configurator/template files were clean in the inspected worktree; the built collectors were used only to enumerate their exact keys. The set contains 1,009 unique paths. It does not include older paths that exist only in migration manifests or the frozen C01 fixture; those are in `migration-cleanup-paths-and-hashes.md` and the main inventory.

# Citation Policy

- Use Pandoc citation syntax: `[@citekey]`.
- Use `references.bib` as the note-vault citation database.
- Keep paper repositories self-contained by exporting paper-specific `references.bib` snapshots into each paper repo.
- Do not cite a paper unless the note or source metadata contains a citekey.
- If a claim comes from a PDF that could not be read, say so instead of filling details from memory.

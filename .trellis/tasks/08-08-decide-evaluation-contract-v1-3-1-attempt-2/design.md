# Attempt-2 operator decision design

The operator consumes exact immutable identities and chooses one closed decision value. No agent recommendation, silence, prior approval, timeout, or malformed/multi-valued response is converted into a decision.

Acceptance establishes only semantic-contract authority for a separately governed future technical campaign. It does not alter live Procedure 1.0.0 selection or authorize implementation. Missing/mismatched evidence produces no decision file. Existing decisions are immutable; retries are additive.
